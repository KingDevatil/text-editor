## 产品概述

文本编辑器桌面应用（Tauri + React + CodeMirror）。用户要求将当前嵌套在侧边栏内的设置面板重构为独立弹窗，优化设置项布局。

## 核心功能

- 将设置面板从 `Sidebar` 中拆分，新建独立 `SettingsPanel` 弹窗组件
- 在顶部 `Toolbar` 最右侧新增设置图标按钮，用于触发弹窗
- 弹窗内按功能模块分类布局：编辑器设置、外观设置、应用设置
- 优化设置项层级与视觉排列，采用左侧分类导航 + 右侧内容区的布局
- 保持与现有 `ThemeEditor` 弹窗的交互和视觉一致性
- `Sidebar` 仅保留文件浏览功能，移除设置 Tab 和设置相关 props
- `SettingsPanel` 内部直接通过 `useEditorStore` 读写设置状态，消除 props drilling

## Tech Stack

- 前端框架：React 19 + TypeScript + Tailwind CSS
- 状态管理：Zustand（`useEditorStore`）+ localStorage 持久化
- 桌面框架：Tauri v2
- 组件风格：CSS 变量主题系统（`--te-*` 系列变量）

## Implementation Approach

### 策略

参考现有 `ThemeEditor.tsx` 的弹窗遮罩层模式（fixed overlay + 居中圆角卡片），新建 `SettingsPanel` 弹窗组件。弹窗内部采用左侧固定宽度分类导航栏 + 右侧可滚动内容区的双栏布局。设置项按功能分为三大模块：编辑器设置（字体、换行、地图等）、外观设置（主题、颜色编辑）、应用设置（默认应用、帮助）。`SettingsPanel` 内部直接订阅 Zustand store 获取/修改设置值，彻底消除当前通过 App.tsx → Sidebar 的大量 props 传递。

### 关键决策

1. **状态管理位置**：`settingsPanelVisible` 使用 App.tsx 的 `useState`（与现有 `showHelp`、`showThemeEditor` 保持一致），不加入 Zustand store 持久化
2. **数据流简化**：`SettingsPanel` 内部直接 `useEditorStore` 读写，不接收设置状态 props。App.tsx 中移除所有通过 Sidebar 传递的设置回调 props
3. **Sidebar 瘦身**：移除 `activeSection` 状态、设置 Tab、设置面板 JSX 和所有设置相关 props，Sidebar 只负责文件浏览
4. **弹窗尺寸**：宽度约 640px，最大高度 85vh，适配现有界面比例

### 性能考量

- `SettingsPanel` 用 `React.memo` 包裹，visible=false 时不渲染内容或仅渲染空壳
- 设置项使用 checkbox/range 原生控件，无复杂渲染
- Zustand 选择器订阅保证只有相关设置变更时重渲染

## Architecture Design

### 组件关系

```
App.tsx
  ├── Toolbar (新增 onToggleSettings props, 新增设置按钮)
  ├── Sidebar (移除所有设置相关 props, 移除设置面板内容)
  ├── SettingsPanel (新增, 独立弹窗, 内部直接连接 useEditorStore)
  ├── ThemeEditor (已有, 由 SettingsPanel 内触发)
  └── EditorHelp (已有, 由 SettingsPanel 内触发)
```

### 数据流

SettingsPanel 内部直接 `useEditorStore(selector)` 读取/修改设置值，不再经过 App.tsx props 传递。

## 设计方法

弹窗采用与 `ThemeEditor` 一致的遮罩层设计：全屏半透明暗色遮罩 + 居中圆角卡片。卡片内部采用左右双栏布局，左侧为垂直分类导航，右侧为滚动内容区。设置项以分组卡片形式呈现，每组有标题和描述，内部选项采用 label + 控件的标准表单排列。

## 页面规划

### SettingsPanel 弹窗

**整体结构**（从上到下）：

- 顶部标题栏：左侧大标题"设置"，右侧关闭 X 按钮
- 主体区域：左侧 180px 固定导航 + 右侧 flex-1 滚动内容
- 底部：无（内容区自带 padding-bottom）

**Block 1 — 左侧导航栏**
垂直分类列表：编辑器、外观、应用。当前选中项有左侧高亮指示条和背景色区分。点击切换右侧内容。

**Block 2 — 编辑器设置（右侧内容区第一组）**
卡片标题"编辑器设置"。内部选项纵向排列：

- 字体大小：label + 14px 滑块（10-24）+ 数值显示
- 自动换行：label + 右侧 toggle checkbox
- 显示空白字符：label + 右侧 toggle checkbox（从 StatusBar 移入，统一入口）
- 迷你地图：label + 右侧 toggle checkbox
- 滚动超出末尾：label + 右侧 toggle checkbox
- 大文件性能优化：label + 右侧 toggle checkbox
- 全角半角检测：label + 右侧 toggle checkbox
- 显示行号：label + 右侧 toggle checkbox（新增状态绑定）

**Block 3 — 外观设置（右侧内容区第二组）**
卡片标题"外观"。

- 当前主题：展示 light/dark/custom 文字 + 切换按钮（复用 Toolbar 主题切换逻辑）
- 编辑主题颜色：按钮，点击打开 ThemeEditor

**Block 4 — 应用设置（右侧内容区第三组）**
卡片标题"应用"。

- 设为默认文本编辑器：按钮（Tauri 环境才显示）
- 使用说明：按钮，点击打开 EditorHelp

## 设计风格

参考现有 `ThemeEditor` 弹窗风格：圆角卡片、CSS 变量主题色、简洁表单控件。弹窗整体使用玻璃质感（glassmorphism）背景，与编辑器界面形成清晰的视觉层级区分。内容区选项采用清晰的 label + 控件排列，保持足够的留白和间距。

## 响应式

弹窗宽度固定 640px，最大高度 85vh。在小屏幕上允许水平滚动或缩小至 90vw。
